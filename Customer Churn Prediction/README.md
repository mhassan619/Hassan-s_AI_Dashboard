# Customer Churn Prediction

## Overview
This project predicts customer churn using machine learning algorithms.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

## ML Models
- Logistic Regression
- Random Forest
- XGBoost

## Evaluation Metrics
- Accuracy
- ROC-AUC
- Precision
- Recall
- F1-score

## Results
XGBoost achieved the best performance.

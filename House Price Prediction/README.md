# House Price Prediction

## Overview
This project predicts house prices using machine learning algorithms.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## ML Models
- Linear Regression
- Random Forest Regressor

## Evaluation Metrics
- MAE
- MSE
- R² Score

## Results
Random Forest performed better than Linear Regression.
